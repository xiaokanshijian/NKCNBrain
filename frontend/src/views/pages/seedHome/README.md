# 🧠 NKCN大脑思维导航器 - 独立体验页面

## 访问方式

访问 `/seed` 路径即可进入大脑思维导航器的独立体验页面。

## 功能特性

### 1. 真实数据集成
- **自动加载真实聊天数据**：从localStorage和API获取真实的聊天记录
- **文件列表显示**：显示当前选中的文件
- **卡片列表显示**：显示当前选中的卡片
- **场景信息**：显示当前场景和子场景信息

### 2. 模拟数据功能
- **添加模拟消息**：可以添加模拟的问答对话
- **重置数据**：重置为默认的模拟数据
- **加载真实数据**：重新从系统加载真实数据

### 3. 大脑思维导航器
- **实时思维状态分析**：基于真实聊天数据进行分析
- **四色语境导航**：业务→中性→场景→自然语境的转换
- **智能行动建议**：基于分析结果提供个性化建议
- **动态思维路线图**：可视化思维过程

## 使用方法

### 1. 基本使用
1. 访问 `/seed` 页面
2. 系统会自动尝试加载真实数据
3. 如果加载失败，会使用模拟数据
4. 点击"加载真实数据"按钮可以重新加载

### 2. 数据操作
- **添加消息**：点击"添加消息"按钮添加模拟对话
- **重置数据**：点击"重置"按钮恢复默认模拟数据
- **加载真实数据**：点击"加载真实数据"按钮从系统获取真实数据

### 3. 大脑导航器交互
- **展开/收起**：点击右上角的箭头按钮
- **刷新分析**：点击刷新按钮重新分析思维状态
- **执行行动**：点击建议按钮执行相应的思维引导动作

## 技术实现

### 真实数据获取
```javascript
// 获取聊天记录
const chatResponse = await getChatMsg(chatParams)

// 获取文件列表
const files = localStorage.getItem('fileNameList')

// 获取场景信息
this.sceneName = localStorage.getItem('sceneName')
this.subSceneName = localStorage.getItem('subSceneName')
```

### 后端API集成
- `analyze_thinking_state` - 思维状态分析
- `generate_context_navigation` - 四色语境生成
- `get_action_suggestions` - 智能行动建议

### 错误处理
- API调用失败时自动降级到本地分析
- 数据加载失败时使用模拟数据
- 完整的错误日志和用户提示

## 独立部署

这个页面完全独立于现有的chatwindow功能，不会影响任何现有代码：

1. **独立的组件**：BrainNavigator组件独立存在
2. **独立的数据**：不依赖chatwindow的数据流
3. **独立的API**：使用专门的大脑导航器API
4. **独立的样式**：完全独立的UI设计
