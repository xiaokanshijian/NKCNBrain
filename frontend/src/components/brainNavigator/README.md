# 🧠 NKCN大脑思维导航器

## 功能概述

NKCN大脑思维导航器是一个创新的智能思维状态感知与导航系统，旨在将NKCN从单纯的问答工具升级为**智能思维伙伴**，实现真正的人机混合智商提升。

## 核心特性

### 1. 实时思维状态仪表盘
- **象限感知器**：实时显示用户当前认知象限（Q1/2/4 vs Q3）
- **思维活跃度**：基于提问模式、检索失败率、概念跳跃度计算
- **知识盲区热力图**：显示当前本子中未充分探索的概念领域
- **跨本子思维连接**：显示与其他本子的知识关联度

### 2. 动态思维路线图
- **当前思维路径**：可视化显示从问题到答案的思维轨迹
- **建议探索方向**：基于四色语境分析，推荐下一步思维方向
- **思维跳跃建议**：当检测到思维僵化时，提供跨领域思考建议
- **记忆激活提示**：提醒用户相关的历史卡片和知识片段

### 3. 四色语境导航
- **业务语境**：从业务需求出发，关注实际应用场景和用户价值
- **中性语境**：抽象出中性的技术概念和通用原理
- **场景语境**：构建具体的应用环境和上下文关系
- **自然语境**：升华到自然语言表达，形成直观理解

### 4. 智能行动指引
- **下一步操作建议**：基于当前状态推荐具体行动
- **场景切换建议**：智能推荐何时切换到哪个子场景
- **协作激活**：当检测到思维瓶颈时，建议邀请其他用户协作
- **知识整合提醒**：提示需要整合的分散知识点

## 技术实现

### 前端组件
- `BrainNavigator.vue` - 主组件
- `brain_api.js` - API调用封装

### 后端API
- `analyze_thinking_state` - 思维状态分析
- `generate_context_navigation` - 四色语境生成
- `get_action_suggestions` - 智能行动建议

### 核心算法
- **象限感知算法**：基于问题复杂度、检索失败率、概念跳跃度判断认知象限
- **活跃度计算**：综合考虑交互频率、问题数量、内容复杂度
- **盲区识别**：分析知识领域覆盖度，识别未充分探索的领域
- **语境转换**：实现业务→中性→场景→自然语境的递进转换

## 使用方法

### 1. 在chatwindow.vue中集成
```vue
<BrainNavigator 
  :chatList="chatList"
  :fileNameList="fileNameList"
  :choosedCardIdList="choosedCardIdList"
  :sceneName="sceneName"
  :subSceneName="subSceneName"
  @executeAction="handleBrainAction"
/>
```

### 2. 处理行动事件
```javascript
handleBrainAction(action) {
  switch (action.action_type) {
    case 'clarify':
      // 澄清问题
      break;
    case 'explore':
      // 探索知识
      break;
    case 'activate':
      // 激活思维
      break;
    case 'explore_gap':
      // 探索盲区
      break;
    case 'organize':
      // 整理思路
      break;
  }
}
```

## 视觉特效

### 脑波动画
- 动态脑波背景，根据思维活跃度显示不同频率
- 脉冲动画效果，吸引用户注意

### 知识网络图
- 实时更新的概念关系网络
- 思维路径轨迹可视化

### 状态色彩编码
- 不同象限用不同颜色和动画效果
- 渐变背景和阴影效果

## 创新亮点

1. **实时感知**：不是静态功能，而是动态感知用户思维状态
2. **跨域整合**：整合多个本子的知识，形成全局思维视图
3. **主动引导**：不是被动响应，而是主动提供思维建议
4. **可视化思维**：将抽象的思维过程具象化展示
5. **人机协作**：真正实现人机混合智商提升
