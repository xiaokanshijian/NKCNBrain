# 20261123 卡片语义空间 V3 与关键词图交互更新说明

## 更新内容

- 语义梳理增加 `v3_source_document` 流程。启动时检查本子导入文档的摘要和结构或 Skill 是否就绪，再按文档提取词和属性，形成核心问题、Top 词、层级、四象限与温度计等产物。任务返回进度和失败信息，服务端保留旧版流程路径。
- 关键词图增加 Top 候选更换、待定象限确认、面板建议和意图偏好编辑。钉卡和上传文档会记录为下次梳理可用的意图事件。卡片网格适配新增任务阶段，并展示失败文档信息。
- 图界面增加截图和 PNG 导出能力，局部截图使用新增的 `html2canvas` 依赖。管理页的 P4 增加语义 V3 首选模型和降级模型设置。
- 前端接口封装对应四条新增路由 `/api/semantic_intent_preference`、`/api/semantic_panel_suggest`、`/api/semantic_confirm_pending` 和 `/api/semantic_top_alternative_replace`。

## 建议同一提交

建议提交信息 `feat(semantic): 新增文档级语义梳理与关键词图交互`。服务、路由、前端交互和依赖声明一起提交，依赖清单和锁文件成对保留。

- `frontend/src/components/cardWindow/KeywordNetworkGraph.vue` — 语义空间视图、面板交互与截图导出。
- `frontend/src/views/pages/mainHome/adminIndex.vue` — P4 模型设置文案与表单布局。
- `backend/app_chat/scene_models.py` — P4 四个语义 V3 模型槽位。
- `backend/app_chat/semantic_keyword_service.py` — V3 任务调度、产物加载、意图存储及候选确认。

- `backend/app_chat/semantic_source_v3_pipeline.py`（新增） — 文档就绪判断、逐文档抽词、聚合和排序。
