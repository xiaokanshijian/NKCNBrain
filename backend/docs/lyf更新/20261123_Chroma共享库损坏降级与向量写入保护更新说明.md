# 20261123 Chroma 共享库损坏降级与向量写入保护更新说明

## 更新内容

- 向量库路径解析检查共享 SQLite 文件大小和页信息，并识别损坏类错误。共享库健康时继续使用其中的历史向量，有独立库时可使用混合模式；判定共享库损坏后，切换到本子的独立库路径。
- 跨本上下文的只读探测沿用相同的损坏识别逻辑。文件列表和 Chroma 解锁调度改用统一路径解析，避免直接打开固定的共享库目录。
- 文档向量批量入库、复制与批改 RAG 索引改用 `add_documents_durable`。实现包含本地写操作跟踪、SQLite WAL 和检查点处理，以及进程退出时等待未完成写入。

## 建议同一提交

建议提交信息 `fix(chroma): 降级损坏共享库并保护向量写入`。统一路径和持久化写入帮助函数应与调用方一起提交。本组可独立于语义和批改功能提交。

- `backend/llm_langchain/parse_input.py` — 库路径解析、损坏探测、WAL 和写入保护。
- `backend/app_chat/cross_notebook_context.py` — 只读跨本检索解析共享及独立库路径。
- `backend/app_chat/chroma_unlock_scheduler.py` — 解锁调度兜底使用解析后的主库路径。
- `backend/app_chat/views.py` — 卡片文件列表使用解析后的主库路径。
- `backend/app_chat/homework_grading/grading_rag.py` — 批改 RAG 写入使用统一的持久化封装。
