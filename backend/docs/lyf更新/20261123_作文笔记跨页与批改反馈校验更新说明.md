# 20261123 作文笔记跨页与批改反馈校验更新说明

## 更新内容

- 作文优先按自然段或相近意群分框，保留页缘续写。开放材料默认启用 Pass1.5，作文增加连续页候选，有相邻页且当页文字可读时，复核会纠正单纯因跨页而出现的待确认结论。
- 笔记按相近内容区组织主体记录、旁批和标记，识别下划线、圈画、涂色、箭头等，并结合来源、印刷页码和内容线索决定是否衔接邻页。标注本身可作为观察证据。
- 加强模型输出的约束和兜底。统一非标准 `verdict`，将可恢复的 `next_steps` 文本整理成建议数组，支持从完整 JSON 或可用的局部修复中恢复反馈。模型漏给核验短句的题目使用通用短句，其他题目保留已生成的建议。
- 批改成品在幻觉复核后再次核对证据并绑定最终页面。解释精要卡把“看到”和“说明”内容拆为可读的编号要点。

## 建议同一提交

单独拆分时，建议提交信息 `fix(homework): 改善作文笔记跨页和反馈校验`，顺序排在班级多人提交之后。托管规则、提示词、跨页修补、模型输出修复和展示需要采用同一套口径。

整文件纳入

- `backend/app_chat/homework_grading/data/managed_feedback_rules.json` — 更新笔记和作文的托管版面与跨页规则。
- `backend/app_chat/homework_grading/feedback_material_kinds.py` — 补充作文和笔记类型判断。
- `backend/app_chat/homework_grading/feedback_prompts.py` — 开放材料分框、跨页提示和建议数组约束。
- `backend/app_chat/homework_grading/grader_pass1_5.py` — 作文跨页衔接及笔记材料证据提示。
- `backend/app_chat/homework_grading/grader_pass1_review.py` — 修正作文因相邻页边界被过度标记待确认的情况。
- `backend/app_chat/homework_grading/grader_pass2.py` — 规范开放材料总览的 `next_steps`。
- `backend/app_chat/homework_grading/material_markings.py` — 汇总开放材料单元时复用判定值归一化。
- `backend/app_chat/homework_grading/memory.py` — 统一逐页理解与待批清单的判定值。
- `backend/app_chat/homework_grading/model_output.py` — 调整模型 JSON 请求、重试和校验回退处理。
- `backend/app_chat/homework_grading/note_evidence.py` — 区分“才不会”等预防性措辞与真实能力缺陷断言，减少笔记反馈误拦截。
- `backend/app_chat/homework_grading/note_page_links.py` — 扩展笔记候选页对及显式续写线索。
- `backend/app_chat/homework_grading/partial_feedback.py` — 部分反馈降级时保留可用的下一步建议。
- `backend/app_chat/homework_grading/validation_issues.py` — 规整建议项，兼容完整反馈和局部修复。
- `backend/app_chat/homework_grading/verify_suggestions.py` — 按本页待核验题号保留完整建议，缺项回退到通用短句。

共享文件按功能选取差异块

- `backend/app_chat/homework_grading/cross_page.py` — 选取开放材料默认跨页、作文连续页候选和跨页修补回写。学生页段过滤随班级多人组。
- `backend/app_chat/homework_grading/prompts.py` — 选取 `OPEN_MATERIAL_OUTPUT_CONTRACT` 及开放材料建议格式。印刷页眉随班级多人组。
- `backend/app_chat/homework_grading/excerpt_html_views.py` — 选取“看到／说明”的编号拆分、渲染和对应样式。
- `backend/app_chat/homework_grading/staged_pipeline.py` — 选取开放材料交付核验及幻觉复核后最终证据、说明和渲染一致性相关差异。遇到和检查点分支交叠的差异时，可将两组作为一个批改提交。
