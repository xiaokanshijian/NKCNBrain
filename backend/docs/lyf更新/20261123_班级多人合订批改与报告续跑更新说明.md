# 20261123 班级多人合订批改与报告续跑更新说明

## 更新内容

- 一张批改配置卡可以混排单人和班级多人材料。班级材料登记班级号、人数、作业次第及每生页数。开改弹窗通过 `POST /api/ci/homework/class_multi_plan` 查询同班同科的其他次第、前序结果和配置提示。
- 前端可只处理当前文件，也可按作业次第依次运行。多次流程支持沿用前序结果或从头重做，队列状态按本子记录，续跑完成后可接回后续作业。
- 后端按每生页数划分合订 PDF，可复用首位学生的印刷版面并从卷面补全姓名。跨页修补限制在同一学生页段内，报告的全局题号证据经过校验。班级任务按人数调整阶段和总任务预算。
- 批改续跑根据检查点和已有产物定位中断步骤。仅重出报告和卡片时复用已有逐页批改，从记忆汇总开始重建下游结果。
- 班级模式生成个人报告、班级报告和按次记忆，集中沉淀为一张班级解释精要卡。卡片展示班级、学生和逐页内容，并复用人工核验与迭代交互。本子已有语义摘要可以作为批改和期望水准的输入，缺少摘要时仍可运行。

## 建议同一提交

建议提交信息 `feat(homework): 支持班级多人合订批改和报告续跑`。配置卡、计划接口、前端队列、后端执行、核验和卡片入口属于同一链路。

整文件纳入

- `frontend/src/api/continuous_image.js` — 班级计划请求封装。
- `frontend/src/components/fileWindow/HomeworkGradingPanel.vue` — 班级重批范围、前序选择与仅重出报告入口。
- `backend/app_chat/grading_config_card.py` — 解析多人材料配置并生成学生页段。
- `backend/app_chat/views_continuous_image.py` — 接入班级计划查询视图。
- `backend/app_chat/views_card_html.py` — 按分析和版本读取或重建班级解释精要 HTML。
- `backend/app_chat/homework_grading/class_multi_grading.py`（新增） — 学生映射、版面复用、姓名补全、个人和班级报告、历次记忆与班级卡片。
- `backend/app_chat/homework_grading/semantic_feedback_brief.py`（新增） — 将已有语义摘要转成批改指引和期望水准输入。
- `backend/app_chat/homework_grading/excerpt_card_render.py` — 提取印刷页眉，供精要卡展示。
- `backend/app_chat/homework_grading/execution_control.py` — 重置阶段预算窗口并按班级人数扩展预算。
- `backend/app_chat/homework_grading/feedback_rerun_plan.py` — 检查已有逐页结果并设置报告重跑起点。
- `backend/app_chat/homework_grading/feedback_start_service.py` — 保留续跑位置、班级映射和前序策略。
- `backend/app_chat/homework_grading/homework_versions.py` — 在版本克隆时保留班级产物目录。
- `backend/app_chat/homework_grading/ontology_builder.py` — 从题目单元等产物补齐 L5 合法题号，过滤无来源引用。
- `backend/app_chat/homework_grading/result_cards.py` — 多人模式只钉解释精要卡，并兼容卡片数据库的字符限制。
- `backend/app_chat/homework_grading/verify_loop.py` — 人工核验迭代后重建班级产物。

共享文件按功能选取差异块

- `frontend/src/views/mainPage.vue` — 随本组提交批改配置模板、班级开改选择、队列与续跑、报告重跑和结果卡刷新。语义 API 导入及钉卡、上传事件随语义组。
- `backend/app_chat/urls.py` — 将 `ci/homework/class_multi_plan` 路由随本组提交。
- `backend/app_chat/homework_grading/cross_page.py` — 选取 `_filter_groups_by_page_runs` 及 `resolve_cross_pages` 调用和参数中的学生页段限制。
- `backend/app_chat/homework_grading/prompts.py` — 选取印刷页眉约束、页眉清理及补充识别和批改提示接入。
- `backend/app_chat/homework_grading/excerpt_html_views.py` — 选取共享的核验嵌入、期望水准和作业研判面板及所需样式。
- `backend/app_chat/homework_grading/staged_pipeline.py` — 选取班级上下文、版面复用、检查点和报告续跑、按学生缩小跨页范围、姓名补全、班级报告、钉卡和语义指引接入。

如果要把后端按文件整份提交，建议将本组和《开放材料跨页与批改反馈校验更新说明》合成一个批改提交，因为两组在跨页和阶段编排中有交叠。前端主页面与后端路由的语义部分仍需按差异块拆开。
