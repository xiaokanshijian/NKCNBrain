# 20261123 语义四象限结果导入导出工具更新说明

## 更新内容

- 导出脚本从已有笔记本语义结果生成 `nkcn_quadrant_bundle_v1` 数据包，包含四象限内涵、逐词象限记录及词条的 `quadrant`、`status`、`pending_faded` 字段。
- 导入脚本按用户名及可选场景定位目标本子，更新语义元数据和词条象限字段，并备份现有的四象限 JSON 文件后写入新结果。脚本直接使用已生成的结果，无需发起模型任务。
