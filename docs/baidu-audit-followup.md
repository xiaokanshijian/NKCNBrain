# 百度文档翻译凭据漏检：核实与本地补修

## 核实结论

独立复核确认 Claude 指出的百度文档翻译凭据问题属实：
backend/app_chat/baidu_trans_doc.py 原先把应用标识和 seckey 写成常量，
该 seckey 用于 HMAC 签名，并存在于当前公开的两个提交中。

此前扫描依赖常见 token 前缀和有限字段名，没有识别 self.seckey。
以前的“零命中”只代表当时规则和已知值检查未命中，不代表完整脱敏。
本记录修正此前清理结果的覆盖范围说明，不展示原值。

## 本地改动

- 百度应用标识与签名密钥改用 BAIDU_TRANS_APPID、BAIDU_TRANS_SECKEY 环境变量。
- 示例配置中的两个值均为空，配置映射已补齐。
- 缺少配置时，翻译请求在读取文件和发出网络请求前给出明确错误；
  可选翻译服务未配置不会阻断 Django 导入与启动检查。
- 原 HMAC 签名拼接、编码与响应处理保持一致。
- 配置日志和保存检查覆盖 seckey 等别名。
- 扫描器增加 AST 属性/字典/参数检测、环境变量默认值与 or/条件回退、
  JSON/env/JS 字段检测、注释检测和历史版本扫描。
- 发布检查现在也验证 PUBLIC_RELEASE_MANIFEST.json 与实际文件一致。
- 测试例外绑定文件、字段、规则和具体值指纹，并附有复核原因；
  没有忽略整个测试目录或放行真正的 token 格式。
